# 10 — 1920x1080 tests (2026-11-20, owner insists on 1080p)

All tests: Chrome 1920x1080 window, `low=0`, sandbox, `slots=5`, `log=1`, particles/grass/city/LOD 0, measured after `world shown`.

| Settings | Steady FPS | Draws/frame | Worker |
|---|---|---|---|
| 1920x1080, texture 2, **shadow 2, reflection 2** (max) | **5.6** | 2743 | 99% |
| 1920x1080, texture 2, shadow 0, reflection 1 (optimized) | **~8** | 2700-2820 | 93-96% |
| 960x540, same optimized settings (from 09) | **16.5-16.8** | 1150-1250 | 98-99% |

**Conclusion:** True 1920x1080 internal rendering is not viable on i3-7100U / HD 620 in this port. The WebGPU worker is draw-bound; 1080p also emitted ~2x the draws of 960x540 in these sandbox scenes.

**Best compromise for a 1080p-looking screen:** run `res=960x540&fx=hd` maximized — the compositor upscales to 1920x1080 with unsharp/contrast (see 07). Delivers ~16 FPS with a 1080p-sized, sharpened image. Do not claim 25-30 FPS at true 1080p.
